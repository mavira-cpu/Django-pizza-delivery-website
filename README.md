# 🍕 Pizzon - Pizza Delivery Website

A full-featured pizza ordering website built with Django.

## Features

- 🏠 Beautiful home page with popular items
- 📋 Menu with categories and filtering
- 🛒 Shopping cart (session-based)
- 💳 Checkout with order processing
- 👤 User authentication (register/login)
- 📦 Order history for users
- 📊 Admin dashboard
- 📱 Fully responsive design

## Tech Stack

- **Backend**: Django 5.2
- **Database**: SQLite (development)
- **Frontend**: HTML, CSS, JavaScript
- **Images**: Pillow
